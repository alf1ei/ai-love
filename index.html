Conversation Principles

01 · Context over tricks
回应具体内容，而不是套用话术。
02 · Respect boundaries
对方不回复或表达拒绝时，尊重选择。
03 · Be yourself
不编造身份、收入、生活经历或承诺。
04 · Reciprocity matters
关注双方主动性，而非单方面投入金额。

Architecture Notes

当前 MVP 使用原生 HTML / CSS / JavaScript，无构建依赖。后续可拆分为 Next.js 前端、FastAPI 服务层、SQLite/PostgreSQL 数据层和可选的服务端多模态模型适配器。API Key 不应放在浏览器端。

Responsible Use

不自动登录平台、不绕过访问控制、不抓取非公开信息、不自动付款、不自动发送私信。关系状态只接受明确披露或人工确认，未知状态不会被推断为单身。所有评分仅作自我反思参考。
